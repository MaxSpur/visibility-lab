# Affiliation artwork

These are the user-supplied logos from the workspace root, copied for the portable laboratory. SVG artwork remains vector; the build embeds every asset as a data URI so the generated HTML works offline.

- `geovis.png`: transparent top/bottom padding cropped from the original 1300 × 1280 image to 1300 × 1032. [Geovis](https://www.umr-lastig.fr/geovis/).
- `lastig.svg`: viewBox tightened to the black artwork, retaining its white background and a half-unit anti-alias margin. [LASTIG](https://www.umr-lastig.fr/).
- `ign.svg`: original viewBox retained; the artwork already fills it. [IGN](https://www.ign.fr/).
- `geodata.svg`: transparent margins removed by tightening its viewBox, retaining a half-unit anti-alias margin. [Géodata Paris](https://geodata-paris.fr/).
- `eiffel.svg`: original viewBox retained; the artwork already fills it. [Université Gustave Eiffel](https://www.univ-gustave-eiffel.fr/).

No logo shapes, colors, or lettering were redrawn. The author link points to [Maxim Spur's LASTIG page](https://www.umr-lastig.fr/maxim-spur/).
